# Analytics

## Goal

Use analytics to understand gameplay quality, retention and monetization while applying privacy-by-design principles.

## Planned event categories

### Gameplay

- Session started
- Run started
- Run ended
- Death / failure
- Distance / score reached
- Hook interaction
- Major progression milestone

### Retention

- First launch
- Returning session
- Day-based retention metrics

### Monetization

- Ad shown
- Rewarded ad completed
- Purchase initiated
- Purchase completed
- Restore purchase

## Principles

- Collect only data that has a clear product purpose.
- Avoid unnecessary personal data.
- Document every analytics SDK and its data practices.
- Keep analytics decoupled from core gameplay where practical.
- Review platform and GDPR requirements before production use.
