# Monetization

## Status

No monetization is implemented yet. Gameplay validation comes first.

## Potential model

The current direction is a free-to-play core game with optional monetization. Possible components:

- Rewarded ads
- Interstitial ads where appropriate
- Remove Ads purchase
- Premium worlds / content
- Cosmetics

These are hypotheses, not final commitments.

## Principles

- Monetization must not undermine the core gameplay.
- Rewarded ads should provide clear optional value.
- Purchases for digital content must use the relevant platform billing systems.
- Monetization decisions should be informed by player behavior and testing.
- Avoid building a complex economy before the core game has proven itself.

## Open decisions

- Ad provider
- Ad frequency
- Reward design
- IAP catalog
- Pricing
- Premium content strategy
- Whether cosmetics are worth supporting
