# Roadmap

This roadmap is intentionally lightweight. Scope should expand only after the core gameplay has been validated.

## Phase 0 — Project setup

- [x] Create repository
- [x] Establish documentation structure
- [ ] Select cross-platform game technology
- [ ] Establish initial project structure

## Phase 1 — Proof of concept

Target: approximately 5–10 development hours.

- [ ] Basic player movement
- [ ] Hook interaction
- [ ] Swing physics
- [ ] Release mechanic
- [ ] Camera follow
- [ ] Restart / failure state
- [ ] Basic temporary visuals

**Success criterion:** the core swing/release loop feels worth iterating on.

## Phase 2 — Playable prototype

Target: approximately 15–30 total hours.

- [ ] Tune physics and game feel
- [ ] Multiple hook configurations
- [ ] Basic procedural or semi-procedural path generation
- [ ] Score / distance
- [ ] Basic obstacles
- [ ] First sound effects
- [ ] Basic UI

## Phase 3 — MVP

Target: approximately 30–50 total hours.

- [ ] Reliable game loop
- [ ] Progression concept
- [ ] More gameplay variety
- [ ] Analytics foundation
- [ ] Audio system
- [ ] Performance testing
- [ ] iOS and Android test builds

## Phase 4 — Commercial candidate

Indicative target: approximately 60–100+ total hours, depending on scope.

- [ ] Onboarding
- [ ] Polished visuals
- [ ] Full audio pass
- [ ] Monetization implementation
- [ ] Ads / rewarded ads if validated
- [ ] In-app purchases if validated
- [ ] Privacy / compliance implementation
- [ ] Store assets and listings
- [ ] Crash monitoring
- [ ] Device testing

## Phase 5 — Post-launch

Only after launch data validates demand:

- [ ] Additional worlds
- [ ] New mechanics
- [ ] Cosmetics
- [ ] Events / challenges
- [ ] Content updates
- [ ] Monetization optimization

Dates are intentionally not fixed yet.
