# Design System

## Status

Design system is not finalized.

## Current direction

The visual identity should support:

- Clear gameplay readability.
- Strong contrast between player, hooks and hazards.
- Satisfying motion feedback.
- A distinctive but maintainable visual identity.
- Mobile-first controls and UI.

## Open decisions

- Final visual style
- Color palette
- Typography
- Player design
- Hook design
- World themes
- UI style
- Animation language

These decisions should be documented when made rather than assumed in advance.
